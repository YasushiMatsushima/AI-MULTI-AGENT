# Python Webフレームワーク比較レポート

## 比較表

| 観点 | FastAPI | Flask | Django |
|------|---------|-------|--------|
| **学習コスト** | 中（型ヒント知識が前提） | 低（最小構成で即起動） | 高（ORM/admin等の概念が多い） |
| **非同期サポート** | ネイティブ（ASGI標準） | 限定的（Flask 2.0以降、部分対応） | 部分的（Django 3.1以降、完全ではない） |
| **バリデーション** | Pydantic統合（自動） | 別途ライブラリ必要 | Forms/Serializers（Django REST Framework） |
| **APIドキュメント** | 自動生成（Swagger/ReDoc） | 別途ライブラリ必要 | DRFで対応可 |
| **ORM** | SQLAlchemy等（選択自由） | SQLAlchemy等（選択自由） | Django ORM（組み込み） |
| **認証** | 別途実装 or ライブラリ | Flask-Login等 | django.contrib.auth（組み込み） |
| **Admin画面** | なし | なし | 自動生成（強力） |
| **パフォーマンス** | 高（uvicorn/非同期） | 中（WSGI同期） | 中（WSGI、非同期対応進行中） |
| **適合規模** | 小〜大（API特化） | 小〜中（汎用軽量） | 中〜大（フルスタック） |

---

## 各フレームワーク詳細

### FastAPI

**長所**
- `async/await` がネイティブで動作、I/Oバウンドな処理で高スループット
- Pydanticによるリクエスト/レスポンスの型バリデーションが自動
- OpenAPI仕様のドキュメントを追加コスト0で生成
- Python 3.10+ の型ヒントと自然に統合
- uvicorn + ASGI でベンチマーク上位（Flaskの2〜5倍程度）

**短所**
- 管理画面、セッション管理、フォームなどは自前実装が必要
- 型ヒントの理解が前提（初心者には若干の壁）
- エコシステムはFlask/Djangoより若い

---

### Flask

**長所**
- 最小限の構成で即稼働（Hello Worldが5行）
- 学習リソースが豊富、初心者に最も入りやすい
- 拡張性が高く「必要なものだけ追加」の思想
- レガシーシステムとの統合がしやすい

**短所**
- 非同期は後付け対応で一貫性が低い
- バリデーション・ドキュメント生成は別途設定が必要
- 大規模化時にアーキテクチャが散漫になりやすい
- パフォーマンスは3者中最低水準（WSGI同期）

---

### Django

**長所**
- フルスタック「電池付属」：ORM/認証/Admin/テンプレートが揃っている
- セキュリティ機能（CSRF/XSS対策等）がデフォルト組み込み
- 大規模プロジェクト・チーム開発に強い
- コミュニティが巨大、サードパーティパッケージが豊富

**短所**
- 学習コストが高く、規約が多い（「Djangoの流儀」を学ぶ必要がある）
- 軽量APIには過剰（ボイラープレートが多い）
- 非同期対応はDjango 4.x以降で改善中だが、FastAPIに比べ不完全
- ORMがDjango専用のため他との組み合わせに不向き


## このプロジェクトへの最終推奨

### **推奨: FastAPI（現状維持・強化）**

**根拠：**

1. **既存コードベースとの整合性** — プロジェクトはすでにFastAPIを採用しており、変更コストがゼロ。

2. **Python 3.12との親和性** — FastAPIはPydantic v2 + Python 3.12の型ヒントと完全に統合されており、最新のPython機能を最大限活用できる。

3. **TodoアプリAPI拡張への適合** — Todoアプリ拡張に必要な「バリデーション・自動ドキュメント・非同期DB操作」はFastAPIが最も低コストで実現できる。

4. **uvとの相性** — `uv` による高速パッケージ管理とFastAPIのシンプルな依存関係は相性が良い。追加ライブラリが少なく済む。

5. **将来性** — 非同期I/O（外部API連携、並列処理）の拡張が最も自然に行える。

**補足：** 管理画面や複雑な権限管理が将来必要になった場合は、FastAPIとSQLAdmin等を組み合わせるか、Django REST Frameworkへの移行を検討する余地はある。現時点のスコープではFastAPIが最適。
