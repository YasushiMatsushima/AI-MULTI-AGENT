# エージェント共通コンテキスト

このファイルは `.claude/agents/` 配下の全エージェントが共有するプロジェクト情報です。各エージェント定義ファイルから「`_shared.md` を参照のこと」と参照されることを想定しています。

---

## プロジェクト概要
- Claude Code のマルチエージェント機能を学習する実習プロジェクト
- 詳細は ルートの [CLAUDE.md](../../CLAUDE.md) を参照

## 技術スタック
- Python 3.12
- パッケージ管理: **uv**（pip は使用禁止）
- テスト: pytest
- フレームワーク: FastAPI

## ディレクトリ構成
- `src/` : メインのソースコード
- `tests/` : テストコード
- `docs/` : ドキュメント
- `.claude/agents/` : エージェント定義

## 共通の開発ルール
- コメント・docstring・ドキュメントは**日本語**で記述する
- パッケージ追加: `uv add <pkg>`（`pip install` 禁止）
- スクリプト実行: `uv run python <script>`
- テスト実行: `uv run pytest`
- `src/.env` をコミットしない
- `.venv/` を直接編集しない
- **テストを削除して通過させない**

## エージェント間ワークフロー（標準フロー）

```
[ユーザー要求]
      ↓
   メイン Claude
      ↓
  ┌───────────────────────┐
  │  python-code-reviewer │ ──→ バグ・セキュリティ・パフォーマンス指摘
  └───────────────────────┘
      ↓ （メインが受け取り、コード修正を実施）
  ┌───────────────────────┐
  │     test-engineer     │ ──→ 修正後の「あるべき動作」をテスト化
  └───────────────────────┘
      ↓
  ┌───────────────────────┐
  │      doc-writer       │ ──→ tests を読んで仕様を docstring 化
  └───────────────────────┘
```

詳細なワークフローは [README.md](README.md) を参照。

## エージェント間ハンドオフの原則

- **指摘事項は「修正されるべき問題」として扱う**：python-code-reviewer の指摘を test-engineer が「現状追認テスト」として固定化することは禁止。
- **既知バグを仕様化しない**：doc-writer は既知バグを `Raises:` などに書かない。
- **失敗テスト = Red はバグ検出のシグナル**：test-engineer は Red を見て「コード修正が必要」と構造化して報告する（テストを書き換えて Green にしない）。

## /goal テンプレートの遵守

長時間タスク・マルチエージェント実行では CLAUDE.md の `/goal` 4ブロック構造（context / done when / do not / progress tracking）に従うこと。
