現在、ステージングされている変更を git コミットしてください。
未ステージのファイルには触れないこと（`git add` を実行しない）。

手順:
1. `git status` で変更ファイルを確認する
2. `git diff --cached` でステージング済みの差分を確認する
3. ステージ済みファイルに機密ファイル（.env など）が含まれていたら警告し、ユーザーに確認する
4. 変更内容を端的に表した日本語のコミットメッセージを作成する
5. `git commit -m "メッセージ"` でコミットする

引数が渡された場合はそれをコミットメッセージとして使用する: $ARGUMENTS
